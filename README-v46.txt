Count to Christmas — v46

New in v46
- Prominent live “sleeps until Christmas” number on the homepage.
- Seasonal personal line showing Saturdays remaining plus a changing festive message.
- 24-door Advent Calendar on the homepage.
- Before 1 December all doors are locked.
- From 1–24 December doors unlock progressively using the visitor’s local date.
- Opened doors are remembered on that device using localStorage.
- Each door reveals an original festive fact, joke, trivia item, micro-activity or suggestion.
- After 24 December all doors remain available.
- Mobile-friendly and keyboard-accessible Advent controls.
- Preserves the v45-style content expansion: Christmas Facts, Traditions, How Many Sleeps, Countdown Guide, Around the World, About and Privacy.
- Preserves AdSense, ads.txt, Cloudflare Web Analytics, iPhone audio fallback, snow, share, confetti and home-screen icons.
- Cache-busting updated to v46.
- Sitemap updated for the expanded site.

Deployment
Copy all files into the existing counttochristmas project folder, then:
git add .
git commit -m "Add sleeps hero and Advent calendar"
git push
